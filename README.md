# Recipe CRUD API

CRUD (Create, Read, Update, Delete) application for managing recipes using Node.js, Express.js, and Mongoose.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman

## Installation

1. Clone repository
2. Run: npm install
3. Create: .env file
4. Run: npm run dev
